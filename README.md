# Lean Six Sigma DMAIC Process Control & Learning Operations Engine

## Project Context & Motivation
Leveraging the university-sponsored Google Professional Certificate curriculum alongside self-directed Lean Six Sigma Green Belt (LSSGB) certification prep, this initiative bridges digital analytics engineering with operational excellence methodology. Recognizing the absence of formal institutional Green Belt training, I formulated a personal DMAIC continuous improvement cycle to manage study throughput, minimize cognitive process waste, and systematically de-risk certification outcome.

Unlike traditional enterprise BI systems designed for cross-functional stakeholders with indefinite transactional streams, this project represents an **Agile Self-Operating Control Tower**. The data collection pipeline is longitudinal and active during the 14-week preparation sprint, transitioning into a static, post-project audit baseline upon certification delivery.

## Methodological Rigor: Mitigating Self-Reported Bias
A foundational critique of personal operational logging is the reliance on subjective self-reporting. In this architecture, metric integrity is governed by **Closed-Loop Ground Truth Alignment**:
- **Output-Anchored Validation:** Purely fabricating favorable intermediate metrics (e.g., artificially deflating NVA waste or inflating PCE) offers zero predictive utility if the final certification threshold (IASSC First-Time Pass ≥ 80%) fails. The ultimate standardized examination serves as the uncompromising operational boundary.
- **Systematic Operational Definitions:** Metrics such as Confidence Level and Process Cycle Efficiency (PCE) are tied to explicit behavioral criteria (e.g., independent formula articulation, strict USL/LSL study boundaries), eliminating arbitrary scoring.
- **Statistical Control over Vanity Metrics:** Process variation is monitored via SPC (I-MR Control Charts) and Pareto root-cause diagnostics, treating self-reported friction as tangible defect occurrences requiring Immediate Kaizen Countermeasures (OCAP protocols).

By enforcing strict operational definitions, this dashboard functions not merely as a tracker, but as a defensible, single-operator quality management system transforming abstract study hours into measurable, value-added capability.
